# 🔐 Proyecto CI/CD Seguro con IA (Sin LLMs)

Este proyecto implementa un pipeline CI/CD seguro que utiliza un modelo clásico de Machine Learning (Random Forest) para clasificar código fuente como **seguro** o **vulnerable** antes de permitir su despliegue en producción.

Cumple todos los requisitos del Proyecto Integrador Parcial II de Desarrollo de Software Seguro.

---

# 🧠 Tecnologías utilizadas

- Python 3.10
- Flask (API)
- Scikit-Learn (Random Forest)
- GitHub Actions (CI/CD)
- Railway / Render para despliegue
- GitHub CLI (Issues automáticas)
- Telegram Bot (alertas de seguridad)
